# 🎛️ Audio Analyzer

Essentia 기반 음원 분석 + 유사도 측정 웹앱 (Streamlit)

## 기능
- 리듬(BPM, 댄서빌리티) — 장르 기반 옥타브 자동 보정
- 다이내믹스 / 라우드니스
- 음색(Timbre)
- 감성 지표: acousticness, energy, instrumentalness, valence
- 장르 예측 Top 5 (400종)
- 두 곡 간 임베딩 코사인 유사도 비교

## 배포
Streamlit Community Cloud(share.streamlit.io)에서 이 저장소를 연결하면 바로 배포됩니다.
Main file path: `app.py`
